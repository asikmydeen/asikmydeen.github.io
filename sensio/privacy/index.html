1. Overview & Data Ownership

SensIO ("we", "our", or "us") respects your privacy. This Privacy Policy explains how data is handled when you use the SensIO mobile application and its local API server features.

SensIO is a privacy-first, local-first developer tool. It transforms your Android device into a local REST and WebSocket API server to interface with local scripts, robotics, and AI agents.

  • Zero Cloud Collection: We do not collect, store, transmit, or monetize any of your personal data or sensor telemetry to external cloud servers or third parties operated by us.
  • Local Processing: All device data (including sensors, location, microphone audio levels, camera captures, USB serial streams, and screen touches) is processed exclusively on your device and transmitted only to endpoints on your local network or user-configured private VPN tunnels (e.g., Tailscale, Cloudflare Tunnel).

2. Information Handled by the Local API Server

SensIO acts as a server on your local device. The following data categories may be processed locally and exposed via HTTP/WebSocket endpoints secured by your authentication settings:

  • IMU Motion Sensors: Accelerometer, gyroscope, linear acceleration, rotation vector, and orientation for gesture detection.
  • Touch Coordinates: Screen interaction coordinates (X, Y) and pressure indicators when local touch tracking is active.
  • Location Data: Fine and coarse GPS/network location coordinates (used strictly for local API retrieval when granted).
  • Audio Telemetry: Microphone RMS decibel volume levels and optional raw PCM streaming when enabled (processed in memory for API clients; not uploaded to our servers).
  • Camera Capture: Camera snapshots captured via local API request are saved locally on your device storage and served directly to your authorized API client.
  • USB Host Serial: Data sent to or received from connected USB serial peripherals is bridged locally.
  • Companion Devices: Optional Wear OS or peer device telemetry may be aggregated into local snapshots when you link those devices.

3. Data Protection and Authentication

  • Local Token Authentication: SensIO can enforce Bearer Token authentication when exposed outside of localhost (127.0.0.1), helping prevent unauthorized devices on your network from accessing your device APIs.
  • User Control: Collectors (Location, Sensors, Microphone, Camera, Touchscreen, USB, and related features) can be toggled according to in-app settings and Android system permissions.
  • Foreground Notification: When the bridge is running, Android shows a persistent notification so you know the service is active.

4. Third-Party Services

SensIO does not integrate third-party analytics, tracking SDKs, or advertising networks.

If you choose to use third-party network tunneling software (such as Tailscale or Cloudflare) or other apps on your device to reach your local SensIO API remotely, your traffic is governed by the respective privacy policies of those services.

Distribution via Google Play is subject to Google’s terms and privacy practices for Play services.

5. Children's Privacy

SensIO does not knowingly collect or solicit personal information from children. Because the app is designed so that sensor and media data remain under the user’s control on the device (and optional private tunnels the user configures), we do not operate a cloud service that gathers children’s personal data.

6. Permissions

SensIO requests Android permissions (e.g., Location, Camera, Audio Recording, Foreground Service types, Accessibility when you enable related features, Install packages when you use APK install APIs) solely to provide the local bridge and API functionality you request. These permissions are not used to harvest data in the background for third parties or advertising.

We may update this Privacy Policy from time to time. Updates will be reflected by changing the "Last Updated" date on this page.
